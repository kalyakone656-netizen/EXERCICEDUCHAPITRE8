# Chapitre 08 - Tests Unitaires avec JUnit 5

## Description
Application de gestion d'une bibliothèque virtuelle (BookShelf)
développée avec la méthode TDD (Test Driven Development).
Ce projet illustre l'utilisation de JUnit 5 et AssertJ 
pour écrire des tests unitaires efficaces en Java.

## Structure du projet
- **Book** : Classe représentant un livre avec :
  - Titre
  - Auteur
  - Date de publication
- **BookShelf** : Classe représentant une étagère de livres
- **BookShelfSpec** : Classe de tests unitaires

## Fonctionnalités implémentées

### Exercice page 72 - Tri des livres
- Trier les livres par titre (ordre alphabétique)
- Trier les livres par date de publication (ordre croissant)
- Trier les livres selon un critère personnalisé

### Exercice page 82 - Groupement des livres
- Grouper les livres par année de publication
- Grouper les livres selon un critère personnalisé (ex: auteur)

## Technologies utilisées
- Java JDK 21
- JUnit 5
- AssertJ 3.25.3

## Exécution des tests
1. Ouvrir le projet dans IntelliJ IDEA
2. Clic droit sur `BookShelfSpec`
3. Cliquer sur `Run BookShelfSpec`
